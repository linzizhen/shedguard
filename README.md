# shedguard

> 爬宠蜕皮预警设备：一个夹在饲养箱上的摄像头，AI 识别蜕皮前兆，提前告诉主人「它要蜕了，现在该做什么」。

## 一句话

**它要蜕皮，你先知道。**

## 要解决的问题

爬宠（守宫、鬃狮蜥等）蜕皮前会变白、眼睛浑浊、活动减少，新手往往看不出来。蜕皮期湿度不够就会**卡皮**，导致趾头坏死、尾巴坏死，甚至死亡。

现有产品解决的是「环境稳不稳定」：温湿度监控、自动控温、自动喷雾。但没有人解决一个更具体的问题：

> **它是不是快要蜕皮了？**

## 解决方案

用一个固定在饲养箱上的摄像头，做三件事：

1. **每天定时拍一张**，对比历史照片
2. **识别蜕皮前兆**（体表变白、眼睛浑浊、活动减少），判断「是否进入蜕皮前期」
3. **提前提醒**：告诉主人「它可能 3 天内蜕皮，现在该提高湿度、准备水盆、别打扰」

产品不是又一个智能饲养箱，而是一个「外挂」：夹在玻璃上的支架 + 摄像头，成本低，不改变现有饲养方式。

## 目标用户

- 养干燥型地栖守宫（豹纹、肥尾）的玩家
- 尤其是**刚开始养 1 年内的新手**
- 他们养得很用心，但缺少「看图识状态」的经验

## 使用流程

```
安装摄像头 → 每天自动拍照 → 系统分析 → 推送提醒 → 按清单护理 → 记录蜕皮结果
```

## 技术方案

| 层 | 做法 |
|---|---|
| 硬件 | ESP32-S3-EYE + 红外补光 + 固定支架，夹在饲养箱玻璃上 |
| 拍照 | 定时拍照，断网存 SD 卡，恢复后补传 |
| 分析 | 固定机位 + 每日对比 + 时序判断，不是单张照片识别 |
| 提醒 | 微信/邮件推送 |
| 知识 | 品种参数表 + 蜕皮期护理清单 + 卡皮判断 |

## 与现有产品的区别

| 现有产品 | shedguard |
|---|---|
| 智能饲养箱：控温控湿，不判断个体状态 | 判断「这只守宫是不是要蜕皮了」 |
| 温湿度监控：环境数据，不涉及蜕皮 | 核心指标就是蜕皮前兆 |
| 通用爬宠 App：知识泛化，不做识别 | 针对守宫，做图像识别 + 提醒 |

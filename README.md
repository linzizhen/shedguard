# shedguard

爬宠蜕皮预警设备：一个夹在饲养箱上的摄像头，AI 识别蜕皮前兆，提前告诉主人「它要蜕了，现在该做什么」。

## 一句话

> 它要蜕皮，你先知道。

## 为什么要做

爬宠（守宫、鬃狮蜥等）蜕皮前会变白、眼睛浑浊、活动减少，新手往往看不出来。蜕皮期湿度不够就会**卡皮**，导致趾头坏死、尾巴坏死，甚至死亡。

现有产品（智能箱、温控器）解决的是「环境稳不稳定」，没有人解决「它是不是要蜕皮了」。

## 产品形态

- **硬件**：ESP32-S3-EYE 开发板 + 红外补光 + 固定支架，夹在饲养箱玻璃上
- **软件**：定时拍照 → 图像分析 → 历史对比 → 判断蜕皮前期 → 推送提醒
- **知识**：品种参数卡 + 蜕皮期护理清单 + 卡皮判断

## 当前阶段

M0 — 跑通拍照链路，采集第一只守宫的蜕皮数据。

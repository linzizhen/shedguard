# 蜕皮识别思路

## 为什么要做这个

卡皮（蜕皮不干净）是爬宠新手最容易踩的坑之一，后果可能是趾头坏死、尾巴坏死，甚至死亡。而蜕皮前兆是**可见的**：

- 体表变白、发灰（旧皮与新皮分离）
- 眼睛浑浊（眼罩层）
- 活动减少、躲藏
- 食欲下降

新手看不出来，老手能看出来。产品要做的是把「老手的眼睛」变成可复制的判断。

## 可行性

| 条件 | 说明 |
|---|---|
| 有前兆 | 蜕皮前 2–5 天体色明显变白 |
| 可量化 | 白化本质是亮度/饱和度变化，灰度可测 |
| 有闭环 | 预测「3 天内」，3 天后事实验证，天然标注 |
| 机位固定 | 摄像头不动，同一位置同一角度，对比才有意义 |

## 技术路径

**不是「单张照片识别」，是「固定机位 + 每日对比 + 时序判断」。**

```
每日定时拍照
    ↓
图像预处理（对齐、去噪、亮度归一化）
    ↓
提取信号（体表白度、眼睛区域浑浊度、活动量）
    ↓
与历史基线对比（Z-score / 滑动窗口）
    ↓
多信号 + 时序判断（连续 2–3 天白度上升）
    ↓
判定：蜕皮前期 / 正常 / 不确定
    ↓
推送提醒 + 护理建议
```

## 三个判定信号

| 信号 | 怎么取 | 说明 |
|---|---|---|
| 体表白度 | 守宫身体区域的平均亮度 + 饱和度 | 最主信号 |
| 眼睛浑浊 | 眼部区域对比度下降 | 辅助信号 |
| 活动量 | 帧间差异 / 位置变化 | 活动减少是前兆之一 |

## 验证方法

1. 记录「预测日」：系统说「3 天内会蜕皮」
2. 记录「实际日」：用户点「它蜕皮了」
3. 算准确率：预测对的 / 总预测
4. 持续收集，逐步调阈值

**第一版不要追求高准确率，先追求「能记录、能对比、能看到趋势」。**

## 工程约束

| 约束 | 影响 |
|---|---|
| OV2640 无夜视 | 必须加红外补光（850nm） |
| OV2640 定焦广角 | 支架要伸进箱子，靠近守宫常待处 |
| 守宫夜行 | 默认夜间红外拍摄，白光先不做 |
| 板上算力有限 | 复杂分析放服务器，板上只做拍照和上传 |
| 网络不稳定 | 断网存 SD 卡，恢复后补传 |

## 不做的事

- 不做单张照片「AI 识别蜕皮」（不可靠，会误导）
- 不做诊断（「它生病了」），只做观察提示（「体色变白，可能 3 天内蜕皮」）
- 不承诺准确率，第一版只展示「当前状态 + 历史曲线」

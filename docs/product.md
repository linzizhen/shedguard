# 产品定位

## 一句话

给爬宠主人的「蜕皮预警器」：在它开始蜕皮之前提醒你，并告诉你现在该做什么。

## 用户

- **谁**：养干燥型地栖守宫（豹纹、肥尾）的玩家，尤其是刚开始养 1 年内的新手
- **痛点**：看不出蜕皮前兆，等到卡皮了才发现，卡皮会导致趾头坏死、尾巴坏死甚至死亡
- **替代方案**：靠经验肉眼判断（新手没有）、每天拍照发群里问人（麻烦）、坏死后再找医生（太晚）

## 核心切口：蜕皮识别

不是做又一个「温湿度监控箱」，而是回答一个现有产品回答不了的问题：

> **它是不是快要蜕皮了？**

这个判断有天然闭环：预测「3 天内蜕皮」，3 天后事实会验证，能做准确率，也能持续收集数据。

## 功能三层

| 层 | 内容 | 数据来源 |
|---|---|---|
| 事实层 | 温度、湿度、拍照、喂食记录、蜕皮记录 | 传感器 + 用户一键记录 |
| 标准层 | 品种参数、蜕皮期护理、卡皮处理 | 知识库，标注来源 |
| 判断层 | 是否蜕皮前期、环境是否合适、是否卡皮风险 | AI + 规则，只给建议不给诊断 |

## MVP 边界

只做四件事：

1. 固定摄像头，每日定时拍照
2. 识别「蜕皮前期」，推送提醒
3. 蜕皮期护理清单（湿度要提高、准备水盆、别打扰）
4. 记录这次蜕皮（用了几小时、是否顺利、是否卡皮）

## 非目标

- 不做自动喂食、不控制温湿度、不自动喷水
- 不做整箱，只做外挂（夹在玻璃上的支架 + 摄像头）
- 不做诊断，不替代异宠医生
- MVP 只支持「干燥型地栖守宫」，不一开始就覆盖所有爬宠

## 商业模式

暂不定。先验证「蜕皮提醒」这件事有没有人真的需要。

## 主要风险

| 风险 | 说明 |
|---|---|
| 需求未验证 | 不知道有多少人愿意为「提前知道要蜕皮」付钱 |
| 准确率 | 误报和漏报都会让产品失去信任 |
| 夜行性 | 守宫夜间活动，OV2640 夜拍全黑，需要红外补光 |
| 知识准确性 | 创始人没有爬宠经验，知识须来源可追溯 |
| 硬件供应链 | 一旦量产，需解决外壳、组装、认证 |

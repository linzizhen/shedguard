# 蜕皮状态识别探路记录（2026-11-04）

> 一次性探路，脚本在 `.tmp/spike_state_cls.py`，产物在 `.tmp/state-cls/`，均不入库。
> 目的：验证「蜕皮状态」在图像上是否可分，再决定是否投入三态方案。

## 问题

把「预测蜕皮」收缩为「识别蜕皮状态」后，前提是**状态在图像上有判别力**。若连「正常 vs 蜕皮中」都分不开，三态方案（正常 / 蒙白 / 蜕皮中）不必投入。

## 方法

- 数据：`data/raw/gecko1`，按标注文件自动生成标签——有 `gecko` 框无 `shedding` 框记为 `normal`，两者都有记为 `shedding`。
- 裁剪：取面积最大的 `gecko` 框，外扩 8% 后裁剪，短边 < 24 px 丢弃。
- 样本：train 659（normal 507 / shedding 152）、valid 349（258 / 91）、test 112（80 / 32）。
- 模型：`resnet18` ImageNet 预训练，`fc` 改二分类；224×224；AdamW lr 1e-3；15 epochs；按类别频率加权交叉熵（shedding 权重约 2.17 倍）。

## 结果

| 指标 | 值 |
|---|---|
| 测试集准确率 | **93.75%**（112 张） |
| 正常类 | precision 0.940 · recall 0.975（80 张错 2） |
| 蜕皮类 | precision 0.931 · recall 0.844（32 张错 5） |
| 验证集最好 | 94.56% |

混淆矩阵（行=真值，列=预测）：

|  | normal | shedding |
|---|---|---|
| normal | 78 | 2 |
| shedding | 5 | 27 |

## 结论

**可分性成立**：模型确实能学到「白色皮屑」这个视觉概念，且蜕皮类召回 84.4% 说明不是靠背景蒙对的。

**但 93.75% 不能当产品结论**，原因在数据本身：

1. **物种混杂**。数据集里不只有豹纹守宫，还有睫角守宫、绿鬣蜥，甚至非爬宠图像。产品第一版只覆盖豹纹与肥尾。
2. **标注语义不纯**。`gecko-shedding` 里混着伤口与卡皮的医疗案例（误判样例中一张是绿鬣蜥尾巴缠绷带、残留旧皮），这类图与「正常蜕皮」是不同现象。
3. **分辨率跨度大**。134×128 到 1200×1056 都有，低分辨率图的皮屑肉眼不可辨。
4. **零红外、零蒙白**。现有图全是可见光，且全部是「皮正在脱落」，一张静止蒙白态都没有。

## 对方案的影响

- 探路排除了「特征不可分」这一失败模式，三态方案的技术前提成立。
- 但它**没有**验证产品场景。真实饲养箱（红外补光、固定机位、单一物种、蒙白态）与当前数据分布差距极大，直接拿这个模型上产品会严重过拟合到「白色皮屑特写」。
- 结论：架构可以先落地，模型必须标注为**未经真实数据验证**，等自采数据到位再重训。

## 下一步

1. 落地「YOLO 定位 → 裁剪 → 三态分类」的管线，模型用现有数据训的版本占位，代码与接口按最终形态写。
2. 同时启动真实数据采集（手机临时机位），这是唯一能验证产品的路径。
3. 蒙白样本目前为零，需要专门搜集，且只能靠真实饲养箱影像补齐。

# server

后端：接收图片、存储、分析、推送。

## 职责

1. 接收 ESP32 上传的图片
2. 存储图片与元数据（时间、设备、环境数据）
3. 图像分析（白度、活动量、时序对比）
4. 知识库（品种参数、护理建议）
5. 推送提醒（微信/邮件/App）

## 技术选型

待定。候选：

- 语言：Python（FastAPI / Flask）
- 存储：本地文件 + SQLite（MVP 阶段够用）
- 分析：OpenCV + NumPy
- 推送：Server酱 / 企业微信机器人 / 邮件
